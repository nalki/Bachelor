# 🖥️ 1강.전자계산기 구조 핵심 정리

## 1. 중앙처리장치 (CPU: Central Processing Unit)
컴퓨터의 두뇌 역할을 하며, 데이터의 처리 및 시스템 전체를 제어하는 핵심 장치입니다.

### 🔹 CPU의 주요 명칭
* **중앙처리장치 / CPU**
* **마이크로프로세서 (Microprocessor)**
* **프로세서 (Processor)**
* **집적회로 (IC: Integrated Circuit)**

### 🔹 CPU의 3대 기능
1.  **제어 (Control):** 시스템 전체에 지시 신호를 보냄
2.  **연산 (Operation):** 산술 연산 및 논리 연산 수행
3.  **기억 (Storage):** 레지스터를 통한 일시적 데이터 저장
    * *주의: 입출력(I/O) 기능은 CPU의 핵심 기능에 포함되지 않음*

### 🔹 CPU의 구성 요소
* **제어장치 (Control Unit):** 주기억장치의 명령을 가져와 **해독**하고 각 장치에 **지시 신호**를 보냄
* **연산장치 (ALU):** 산술 연산(+,-,*,/) 및 논리 연산(AND, OR, NOT) 수행
* **레지스터 (Register):** CPU 내부의 **초고속** 일시 기억 장치
* **버스 (Bus):** 각 장치 간 전기 신호를 전달하는 통로 (데이터/주소/제어 버스)

---

## 2. 주기억장치 (Main Memory)
CPU가 직접 접근하여 프로그램과 데이터를 가져오는 고속 기억 장치입니다.

### 🔹 주기억장치 vs 보조기억장치
| 구분 | 주기억장치 (RAM, ROM) | 보조기억장치 (HDD, SSD) |
| :--- | :--- | :--- |
| **속도** | 매우 빠름 | 느림 |
| **용량** | 작음 | 매우 큼 |
| **가격** | 비쌈 | 저렴함 |
| **CPU 접근** | 직접 접근 가능 | 직접 접근 불가 (주기억장치를 거침) |

### 🔹 ROM (Read Only Memory)
* **특징:** 읽기 전용, **비휘발성** (전원이 꺼져도 내용 유지)
* **주요 저장 내용:** BIOS, POST(자체 진단 프로그램), 모니터 프로그램
* **종류:**
    * **Mask ROM:** 제조 시 내용 기록 (수정 불가)
    * **PROM:** 사용자가 1회 기록 가능
    * **EPROM:** 자외선(UV)을 이용해 삭제 및 재기록 가능
    * **EEPROM:** 전기적 신호를 이용해 삭제 및 재기록 가능

### 🔹 RAM (Random Access Memory)
* **특징:** 읽기/쓰기 가능, **휘발성** (전원이 꺼지면 내용 소멸)
* **종류 비교 (DRAM vs SRAM):**
| 항목 | DRAM (동적 RAM) | SRAM (정적 RAM) |
| :--- | :--- | :--- |
| **구성 소자** | 콘덴서 (Capacitor) | 플립플롭 (Flip-Flop) |
| **재충전(Refresh)** | **필요함** | 필요 없음 |
| **속도** | 느림 | **빠름** |
| **집적도/용량** | 높음 (대용량) | 낮음 |
| **주요 용도** | **주기억장치** | **캐시 메모리 (Cache)** |

### 🔹 자기 코어 (Magnetic Core)
* 전류 일치 기술을 이용한 과거의 기억 장치
* **비휘발성**이지만, 데이터를 읽으면 내용이 파괴되는 **파괴성 메모리(DRO)**이므로 재저장이 필요함

# 💾 2강.보조기억장치 핵심 정리

## 1. 보조기억장치 개요
주기억장치의 한정된 용량을 보충하며, 전원이 꺼져도 데이터를 유지하는 **비휘발성** 장치입니다.

### 🔹 주요 특징
* **비휘발성:** 전원 차단 시에도 내용이 소멸되지 않음
* **대용량/저가:** 주기억장치에 비해 용량이 크고 가격이 저렴함
* **간접 접근:** CPU가 직접 접근하지 못하며, 데이터를 주기억장치(RAM)로 읽어온 후 처리함

### 🔹 접근 방식에 따른 분류
1.  **SASD (Sequential Access):** 데이터를 처음부터 순서대로 읽는 방식
    * 예: **자기 테이프 (Magnetic Tape)**
2.  **DASD (Direct Access):** 원하는 위치로 직접 이동하여 읽는 방식
    * 예: **자기 디스크(HDD)**, 자기 드럼, CD-ROM, DVD 등

---

## 2. 자기 테이프 (Magnetic Tape)
순차 접근(Sequential Access)만 가능한 대표적인 SASD 장치입니다.

### 🔹 핵심 개념
* **순차 처리:** 주소 개념이 없으며 처음부터 차례대로 접근함 (검색 속도 느림)
* **블록화 (Blocking):** 여러 개의 논리 레코드를 하나의 물리적 블록으로 묶어 입출력 효율을 높임
* **IBG (Inter Block Gap):** 블록과 블록 사이의 빈 공간 (가속/감속을 위한 간격)
* **블록화 인수 (Blocking Factor):** 한 블록 내에 포함된 논리 레코드의 개수

---

## 3. 자기 디스크 (Magnetic Disk / HDD)
직접 접근(Direct Access)이 가능하며 현재 가장 널리 쓰이는 보조기억장치입니다.

### 🔹 물리적 구조
* **트랙 (Track):** 원판 위의 동심원 통로
* **섹터 (Sector):** 트랙을 부채꼴 모양으로 나눈 최소 기억 단위
* **실린더 (Cylinder):** 여러 장의 원판에서 동일한 위치에 있는 트랙들의 모임
* **엑세스 암 (Access Arm):** 헤드를 지지하고 트랙 사이를 이동시키는 장치

### 🔹 접근 시간 (Access Time) 요소
1.  **Seek Time (탐색 시간):** 헤드가 원하는 **트랙**까지 이동하는 시간
2.  **Latency Time (회전 지연 시간):** 원하는 **섹터**가 헤드 아래로 회전해 올 때까지 기다리는 시간
3.  **Transmission Time (전송 시간):** 데이터를 읽어서 주기억장치로 보내는 시간
    * *공식: Access Time = Seek Time + Latency Time + Transmission Time*

---

## 4. 특수 장치 및 최신 기술
### 🔹 SSD (Solid State Drive)
* 반도체(플래시 메모리)를 이용한 저장 장치
* 기계적 회전이 없어 HDD보다 속도가 매우 빠르고 소음/발열이 적음

### 🔹 RAID (Redundant Array of Independent Disks)
여러 개의 하드디스크를 하나로 묶어 성능과 신뢰성을 높이는 기술입니다.
* **RAID 0 (Striping):** 데이터를 나누어 저장하여 **속도** 향상 (오류 복구 불가)
* **RAID 1 (Mirroring):** 동일 데이터를 두 디스크에 복제하여 **신뢰성** 향상 (백업용)
* **RAID 5:** 패리티(Parity) 정보를 분산 저장하여 성능과 안정성을 동시에 확보

# 🔢 3강.진법과 보수 핵심 정리

## 1. 자료의 구성 단위
컴퓨터가 정보를 표현하는 최소 단위부터 물리적인 저장 단위까지의 계층입니다.

### 🔹 비트 (Bit)
* **정의:** 정보 표현의 **최소 단위** (0 또는 1)
* **n 비트로 표현 가능한 정보의 수:** $2^n$가지
* **기억할 지수값:** 
  * $2^{10} = 1024$ (1K)
  * $2^{16} = 65536$

### 🔹 주요 단위 계층
1.  **Nibble:** 4비트 (16진수 1자리 표현)
2.  **Byte:** 8비트 (**문자 표현의 최소 단위**, 영어/숫자 1자)
3.  **Word:** CPU가 한 번에 처리하는 명령 단위
    * **Half Word:** 2 Byte (16비트)
    * **Full Word:** 4 Byte (32비트)
    * **Double Word:** 8 Byte (64비트)
4.  **기타:** 필드(Field) -> 레코드(Record) -> 블록(Block) -> 파일(File) -> 데이터베이스(DB)

---

## 2. 진법 (Number System)
컴퓨터는 2진수를 기본으로 하며, 효율적인 표현을 위해 8진수와 16진수를 사용합니다.

### 🔹 진법별 특징
* **2진수 (Binary):** 0, 1 사용
* **8진수 (Octal):** 0 ~ 7 사용
* **16진수 (Hexadecimal):** 0 ~ 9, **A(10), B(11), C(12), D(13), E(14), F(15)** 사용

### 🔹 진법 간의 관계
* **8진수 1자리** = 2진수 **3비트**
* **16진수 1자리** = 2진수 **4비트**

---

## 3. 보수 (Complement)
컴퓨터에서 **뺄셈 연산**을 덧셈기(가산기)만으로 수행하기 위해 도입된 개념입니다.

### 🔹 보수의 목적
* **뺄셈의 가산화:** 별도의 감산기 없이 가산기(Adder)만으로 뺄셈을 수행함
* **음수 표현:** 컴퓨터 내부에서 음수 값을 표현하기 위해 사용함

### 🔹 2진수의 보수 구하기
1.  **1의 보수:** 모든 비트를 반전 (0 -> 1, 1 -> 0)
2.  **2의 보수:** **1의 보수 결과에 1을 더함**
    * *빠른 방법:* 오른쪽에서 왼쪽으로 가다가 처음 1을 만날 때까지는 그대로 쓰고, 그 왼쪽 비트들만 모두 반전시킴

### 🔹 보수 연산의 특징
* **1의 보수 연산:** 덧셈 후 최상위 비트에서 **자리올림(Carry)이 발생하면 결과의 최하위 비트에 더함** (End-around Carry)
* **2의 보수 연산:** 덧셈 후 최상위 비트에서 **자리올림이 발생하면 버림** (연산 속도가 더 빠름)

---

# 📂 4강.자료의 외부적 표현 핵심 정리

## 1. 문자 표현 코드
컴퓨터가 외부(인간)로 문자를 보여주기 위해 사용하는 코드 체계입니다.

### 🔹 BCD 코드 (이진화 십진 코드)
* **비트 수:** 6비트 (Zone 2 + Digit 4)
* **표현 능력:** $2^6 = 64$가지 문자 표현 가능
* **특징:** 영문 소문자 표현이 불가능하며, 초창기 대형 컴퓨터에서 사용됨

### 🔹 ASCII 코드 (미국 표준 코드)
* **비트 수:** 7비트 (Zone 3 + Digit 4)
* **표현 능력:** $2^7 = 128$가지 문자 표현 가능
* **특징:** **데이터 통신용** 및 **개인용 컴퓨터(PC)**에서 표준으로 사용됨
* **참고:** 에러 검출을 위해 1비트의 패리티 비트를 추가하여 8비트로 주로 사용함

### 🔹 EBCDIC 코드 (확장 이진화 십진 코드)
* **비트 수:** 8비트 (Zone 4 + Digit 4)
* **표현 능력:** $2^8 = 256$가지 문자 표현 가능
* **특징:** 대형 컴퓨터 시스템에서 주로 사용되는 범용 코드

### 🔹 유니코드 (Unicode)
* **비트 수:** **2 Byte (16비트)** 고정
* **특징:** 전 세계 모든 문자를 2바이트로 통일하여 표현하는 국제 표준 코드

---

## 2. 특수 용도 코드

### 🔹 3초가 코드 (Excess-3 Code)
* **만드는 법:** BCD 코드값에 2진수 3($0011_2$)을 더함
* **특징:** 
    * **비가중치 코드** (자리별 가중값이 없음)
    * **자기 보수 코드** (9의 보수를 간편하게 구할 수 있음)

### 🔹 그레이 코드 (Gray Code)
* **특징:** 
    * 10진수 1씩 증가할 때마다 **비트가 1개만 변함**
    * 아날로그-디지털(A/D) 변환기, 입출력 장치 제어에 사용
    * 비가중치 코드
* **변환법:** 
    * **2진수 → 그레이:** 첫 비트는 그대로, 이후 인접한 비트끼리 XOR 연산
    * **그레이 → 2진수:** 첫 비트는 그대로, 결과값과 다음 그레이 비트를 XOR 연산

---

## 3. 에러 검출 및 정정 코드

### 🔹 패리티 비트 (Parity Bit)
* **목적:** 에러 **검출**용 (정정은 불가능)
* **종류:** 기수(홀수) 패리티, 우수(짝수) 패리티
* **특징:** 1비트의 에러만 검출 가능함 (짝수 개의 에러 발생 시 검출 불가)

### 🔹 해밍 코드 (Hamming Code)
* **목적:** 에러 **검출 및 정정** 가능
* **특징:** 데이터 전송 시 에러가 발생한 비트의 위치를 찾아내어 스스로 수정함
* **패리티 위치:** $2^n$번째 자리(1, 2, 4, 8, 16...)에 패리티 비트를 배치

---

| 분류 | 코드 종류 |
| :--- | :--- |
| **가중치 코드**<br>(Weighted Code) | BCD(8421), 2421, Biquinary, 51111 |
| **비가중치 코드**<br>(Non-Weighted Code, Unweighted Code) | Excess-3, Gray, 2 out-of 5 |
| **자기 보수 코드**<br>(Self-Complementary Code) | Excess-3, 2421, 51111 |
| **오류 검출용 코드** | 패리티 검사 코드, 해밍 코드, Biquinary, 2 out-of 5 |

---

# 5강.정보처리기사: 논리회로 및 부울 대수

## 1. 기본 논리 게이트 (Basic Logic Gates)
컴퓨터의 논리적 사고(참=1, 거짓=0)를 전기 신호로 구현한 전자회로입니다.

| 게이트 종류 | 논리 연산 | 특징 및 기호 | 진리표 특징 | 스위치 연결 |
| :--- | :--- | :--- | :--- | :--- |
| **OR (논리합)** | $A + B$ | 입력 중 하나라도 1이면 출력 1 | 0+0일 때만 0 | 병렬 연결 |
| **AND (논리곱)** | $A \cdot B$ | 모든 입력이 1이어야 출력 1 | 1·1일 때만 1 | 직렬 연결 |
| **NOT (논리부정)** | $\bar{A}$ | 입력의 반대 값을 출력 | 0→1, 1→0 | - |

---

## 2. 결합 및 특수 게이트
기본 게이트를 조합하여 특정 기능을 수행하도록 만든 회로입니다.

*   **NAND (Not AND):** AND 연산 결과를 뒤집은 것 ($ \overline{A \cdot B} $). 모든 입력이 1일 때만 0 출력.
*   **NOR (Not OR):** OR 연산 결과를 뒤집은 것 ($ \overline{A + B} $). 모든 입력이 0일 때만 1 출력.
*   **XOR (배타적 논리합):** 두 입력이 **서로 다를 때** 1 출력 ($ A \oplus B = \bar{A}B + A\bar{B} $). 비교 회로에 주로 사용.
*   **XNOR (배타적 부정 논리합):** XOR의 반대로, 두 입력이 **서로 같을 때** 1 출력.

---

## 3. 부울 대수(Boolean Algebra)의 주요 공식
논리 회로를 간소화하여 효율적인 설계를 돕는 수학적 공식입니다.

| 법칙 종류 | 공식 내용 |
| :--- | :--- |
| **분배 법칙** | $A + (B \cdot C) = (A + B) \cdot (A + C)$ (논리 회로 특유의 공식) |
| **보수 법칙** | $A + \bar{A} = 1$, $A \cdot \bar{A} = 0$ |
| **항등 법칙** | $A + 1 = 1$, $A \cdot 0 = 0$ |
| **드 모르간의 정리** | $\overline{A + B} = \bar{A} \cdot \bar{B}$, $\overline{A \cdot B} = \bar{A} + \bar{B}$ (매우 중요) |
| **이중 부정** | $\bar{\bar{A}} = A$ |

---

## 4. 논리 회로 간소화 (Simplification)
복잡한 식을 부울 대수 공식을 이용해 줄이면, 사용하는 게이트 수를 줄여 비용 절감, 속도 향상, 오류 감소의 효과를 얻을 수 있습니다.

*   **공통 인수 묶기:** $AB + A\bar{B} = A(B + \bar{B}) = A \cdot 1 = A$.
*   **카르노 맵 (Karnaugh Map):** 도표를 이용하여 시각적으로 논리식을 간소화하는 방법 (강의에서는 효율성을 위해 생략 가능하다고 언급).

# 5강.조합 논리회로 (Combinational Logic Circuits)

## 1. 조합 논리회로의 개요
*   **개념:** 기본 논리 게이트(AND, OR, NOT 등)를 조합하여 특정 기능을 수행하도록 만든 회로입니다.
*   **특징:** 
    *   현재의 입력에 의해서만 출력이 결정됩니다.
    *   **기억 기능이 없습니다.** (입력이 사라지면 출력도 사라짐).
    *   종류: 가산기(Adder), 디코더(Decoder), 인코더(Encoder), 멀티플렉서(MUX) 등.

---

## 2. 가산기 (Adder)
이진수의 덧셈을 수행하는 대표적인 조합 논리회로입니다.

| 종류 | 입력 | 출력 | 주요 구성 게이트 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **반가산기(HA)** | 2 bit ($A, B$) | 합($S$), 자리올림($C$) | XOR 1개, AND 1개 | 한 자리 이진수 2개를 더함. |
| **전가산기(FA)** | 3 bit ($A, B, Ci$) | 합($S$), 자리올림($Co$) | 반가산기 2개, OR 1개 | 아랫자리 올림수($Ci$)까지 포함해 더함. |
| **병렬 가산기** | n bit ($A_n, B_n$) | n bit 결과 | 전가산기 n개 연결 | 여러 비트의 이진수를 동시에 더함. |

---

## 3. 디코더와 인코더
*   **디코더(Decoder, 해독기):** n개의 입력선을 통해 들어온 이진 정보를 $2^n$개의 출력선 중 하나로 선택하여 출력합니다. 
    *   주로 AND 게이트와 NOT 게이트로 구성됩니다.
    *   컴퓨터의 제어장치에서 명령어를 해독할 때 필수적입니다.
*   **인코더(Encoder, 부호기):** 디코더의 반대 기능으로, 외부의 신호를 컴퓨터가 이해할 수 있는 이진 코드로 변환합니다.

---

## 4. 멀티플렉서와 디멀티플렉서
*   **멀티플렉서(MUX, Multiplexer):** 여러 개의 입력선 중 하나를 선택하여 **단일 출력선**으로 보내는 회로입니다 (다 대 일).
    *   '데이터 선택기'라고도 하며, 버스(Bus) 구성에 사용됩니다.
*   **디멀티플렉서(DEMUX):** 하나의 입력선으로 들어온 정보를 여러 개의 출력선 중 하나로 골라 보냅니다 (일 대 다).

---

## 5. 조합 논리회로 vs 순차 논리회로 비교
| 구분 | 조합 논리회로 | 순차 논리회로 (순서 논리회로) |
| :--- | :--- | :--- |
| **구성** | 논리 게이트의 조합 | 조합 논리회로 + **플립플롭(기억소자)** |
| **기억 기능** | **없음** | **있음** |
| **특징** | 현재 입력이 출력을 결정 | 현재 입력 + 과거 상태가 출력을 결정 |
| **대표 예시** | 가산기, 디코더, MUX | **레지스터**, 카운터, RAM |

---

# 6강.순서 논리회로 (Sequential Logic Circuits)

## 1. 순서 논리회로의 개념
*   **정의:** 현재의 입력뿐만 아니라 **이전 상태(과거의 출력)**에 의해 출력이 결정되는 회로입니다.
*   **특징:**
    *   **기억 기능(Memory)**이 있습니다.
    *   **귀환(Feedback)** 루프를 포함합니다.
    *   기본 구성 요소: 조합 논리회로 + **메모리 요소(플립플롭)**.
*   **종류:** 플립플롭, 레지스터, 카운터, RAM 등.

---

## 2. 플립플롭(Flip-Flop)의 종류 및 특징
플립플롭은 **1비트**를 기억할 수 있는 최소의 기억 단위입니다.

| 플립플롭 종류 | 특징 및 동작 설명 |
| :--- | :--- |
| **RS 플립플롭** | S(Set), R(Reset) 입력. S=R=1일 때 **상태를 결정할 수 없음(금지)**. |
| **JK 플립플롭** | RS FF의 결점(1,1 입력)을 보완. J=K=1이면 **반전(Toggle)** 발생. |
| **D 플립플롭** | 데이터(Data) 전송용. 입력된 값을 그대로 출력(지연 후 저장). |
| **T 플립플롭** | 토글(Toggle) 전용. 입력이 1이면 출력 상태가 바뀜. |
| **Master-Slave FF** | 출력의 불안정성(Race condition)을 해결하기 위해 두 개의 FF을 직렬 연결. |

---

## 3. CISC vs RISC 프로세서 비교
CPU의 설계 방식에 따른 차이점입니다.

| 비교 항목 | CISC (Complex Instruction Set) | RISC (Reduced Instruction Set) |
| :--- | :--- | :--- |
| **명령어 수** | 많음 (복잡함) | 적음 (단순함) |
| **명령어 길이** | 가변 길이 | **고정 길이** |
| **주소 지정 방식** | 복잡함 | 단순함 |
| **레지스터 수** | 적음 | **많음** |
| **전력 소모** | 높음 | 낮음 |
| **사용처** | 일반 PC (Intel, AMD) | 모바일, 서버 (Apple Silicon, ARM) |

---

## 4. CPU의 구성 요소
*   **ALU (산술논리연산장치):** 사칙연산 및 논리 연산 수행.
*   **제어 장치 (Control Unit):** 명령어 해독 및 신호 제어.
*   **레지스터 (Register):** CPU 내부의 초고속 임시 기억 장치.
    *   **PC (Program Counter):** 다음 실행할 명령어의 주소 저장.
    *   **IR (Instruction Register):** 현재 실행 중인 명령어 저장.
    *   **MAR / MBR:** 주소 및 데이터 버퍼.
*   **버스 (Bus):** 데이터가 이동하는 통로 (내부 버스, 외부 버스).

---

## 5. 성능 지표 및 계산
*   **클록 주파수(Hz):** 1초당 발생하는 신호의 수. (예: 2.5GHz = 1초에 25억 번 진동)
*   **전송량 계산:** (클록 주파수) × (한 번에 전송하는 데이터 폭).
    *   예) 2.5GHz 주파수에서 8비트(1바이트) 전송 시 = 초당 약 2.5GB 전송 가능.
