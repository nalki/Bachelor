### ある
| 구분 | 반말 (보통체) | 존댓말 (정중체) |
| :--- | :--- | :--- |
| 현재긍정 | 本がある | 本があります |
| 현재부정 | 本がない | 本がないです / ありません |
| 과거긍정 | 本があった | 本がありました |
| 과거부정 | 本가なかった | 本がなかったです  / ありませんでした |

### いる
| 구분 | 반말 (보통체) | 존댓말 (정중체) |
| :--- | :--- | :--- |
| 현재긍정 | 猫がいる | 猫がいます |
| 현재부정 | 猫がいない | 猫がいないです  / いません |
| 과거긍정 | 猫がいた | 猫がいました |
| 과거부정 | 猫がいなかった | 猫がいなかったです  / いませんでした |

### い / な형용사 예외 

⭐い로 끝나지만 '나형용사'인 단어들

- 가장 주의해야 할 단어들입니다. '이'로 끝나서 이형용사처럼 보이지만, 실제로는 **な**로 연결하고 활용도 나형용사의 규칙을 따릅니다.

  - きらい: 싫어하다
  - とくい: 자신 있다, 잘하다
  - にがて: 자신 없다, 서툴다
  - さいわい: 다행이다, 행복하다
  - ていねい: 정중하다, 친절하다
  - きれい: 깨끗하다, 예쁘다

⭐な형용사처럼 보이지만 'い형용사'인 경우

- 이 경우는 단어의 끝이 '이'가 아닌 것처럼 느껴지거나, 한자어라서 나형용사일 것 같지만 실제로는 이형용사인 경우입니다.
    - 黄色い(きいろい): 노랗다
    - 茶色い(ちゃいろい): 갈색이다
    - 四角い(しかくい): 네모나다
    - 丸い(まるい): 둥글다

### 반대되는 형용사

- 크기·수치 (Size & Value)
    - 높다 / 낮다: 高(たか)い / 低(ひく)い
    - 길다 / 짧다: 長(なが)い / 短(みじか)い
    - 많다 / 적다: 多(おお)い / 少(すく)ない
    - 크다 / 작다: 大(おお)きい / 小(ちい)さい

- 거리·속도 (Distance & Speed)


멀다 / 가깝다: 遠(とお)い / 近(ちか)い 

빠르다 / 느리다: 早(はや)い / 遅(おそ)い 

넓다 / 좁다: 広(ひろ)い / 狭(せま)い 

깊다 / 얕다: 深(ふか)い / 浅(あさ)い 

- 무게·두께 (Weight & Thickness)
무겁다 / 가볍다: 重(おも)い / 軽(かる)い 

두껍다 / 얇다: 厚(あつ)い / 薄(うす)い 

굵다 / 가늘다: 太(ふと)い / 細(ほそ)い 

- 난이도·강도 (Difficulty & Strength)

보안 엔지니어 교육생으로서 학습이나 과제 강도를 말할 때 쓰기 좋습니다.

어렵다 / 쉽다: 難(むずか)しい / 易(やさ)しい 

강하다 / 약하다: 強(つよ)い / 弱(よわ)い 

딱딱하다 / 부드럽다: 硬(かた)い / 柔(やわ)らかい 

- 가격·기분 (Cost & Emotion)
 
비싸다 / 싸다: 高(たか)い / 安(やす)い 

기쁘다 / 슬프다: 嬉(うれ)しい / 悲(かな)しい

좋다 / 나쁘다: 良(よ)い / 悪(わる)い

### 동사의 반대말

- 전자기기 및 불빛 (켜다 / 끄다)

つける: (불을) 켜다, (스위치를) 올리다

けす: (불을) 끄다, 지우다

- 일상 동작 (열다, 넣다, 입다 등)

| 긍정 의미 | 한자 | 부정 의미 | 한자 |
|-----------|------|-----------|------|
| あける (열다) | 開ける | しめる (닫다) | 閉める |
| いれる (넣다) | 入れる | だす (꺼내다) | 出す |
| のる (타다) | 乗る | おりる (내리다) | 降りる |
| ぬぐ (벗다) | 脱ぐ | きる (입다) | 着る |
| かう (사다) | 買う | うる (팔다) | 売る |



- 이동 및 방향 관련
 
いく (이쿠) : 가다 <-> くる (쿠루) : 오다

はじまる (하지마루) : 시작되다 <-> おわる (오와루) : 끝나다

あがる (아가루) : 올라가다 <-> さがる (사가루) : 내려가다

- 추상적/상태 관련
 
わすれる (와스레루) : 잊다 <-> おぼえる (오보에루) : 외우다/기억하다

わらう (와라우) : 웃다 <-> なく (나쿠) : 울다

ふえる (후에루) : 늘다 <-> へる (헤루) : 줄다

# 📖 일본어 필수 자동사·타동사 정리 (독학사/JLPT 대비)

일본어의 자동사와 타동사는 어미 변화에 따라 일정한 규칙을 가진 쌍이 많습니다. 문맥에 맞는 조사(**が** vs **を**) 사용에 유의하며 학습하세요.

---

## 1. -ある(자동사) / -える(타동사) 형태
가장 빈번하게 출제되는 유형입니다.

| 자동사(자) | 의미 | 타동사(타) | 의미 |
| :--- | :--- | :--- | :--- |
| **上がる** (あがる) | 올라가다 | **上げる** (あげる) | 올리다 |
| **下がる** (さがる) | 내려가다 | **下げる** (さげる) | 내리다 |
| **閉まる** (しまる) | 닫히다 | **閉める** (しめる) | 닫다 |
| **止まる** (とまる) | 멈추다 | **止める** (とめる) | 멈추다/세우다 |
| **始まる** (はじまる) | 시작되다 | **始める** (はじめる) | 시작하다 |
| **掛かる** (かかる) | 걸리다 | **掛ける** (かける) | 걸다 |
| **決まる** (きまる) | 정해지다 | **決める** (きめる) | 정하다 |
| **見つかる** (みつかる) | 발견되다 | **見つける** (みつける) | 찾다/발견하다 |

---

## 2. -う(자동사) / -える(타동사) 형태
어미가 -u로 끝나고 -eru로 변하는 유형입니다.

| 자동사(자) | 의미 | 타동사(타) | 의미 |
| :--- | :--- | :--- | :--- |
| **立つ** (たつ) | 서다 | **立てる** (たてる) | 세우다 |
| **開く** (あく) | 열리다 | **開ける** (아ける) | 열다 |
| **付く** (つく) | 붙다/켜지다 | **付ける** (つける) | 붙이다/켜다 |
| **届く** (とどく) | 도착하다 | **届ける** (とどける) | 배달하다/신고하다 |
| **並ぶ** (ならぶ) | 줄 서다 | **並べる** (ならべる) | 나열하다 |
| **育つ** (そだつ) | 자라다 | **育てる** (そだてる) | 키우다 |

---

## 3. -る(자동사) / -す(타동사) 형태
자동사가 1·2단 동사인 경우가 많으며, 타동사는 -su로 끝납니다.

| 자동사(자) | 의미 | 타동사(타) | 의미 |
| :--- | :--- | :--- | :--- |
| **起きる** (おきる) | 일어나다 | **起こす** (おこす) | 깨우다/일으키다 |
| **落ちる** (おちる) | 떨어지다 | **落とす** (おとす) | 떨어뜨리다 |
| **出る** (でる) | 나가다/나오다 | **出す** (だす) | 내보내다/내다 |
| **消える** (きえる) | 꺼지다 | **消す** (けす) | 끄다/지우다 |
| **回る** (まわる) | 돌다 | **回す** (まわす) | 돌리다 |
| **治る** (なおる) | 병이 낫다 | **治す** (なおす) | 병을 고치다 |

---

## 4. -れる(자동사) / -す(타동사) 형태
파괴나 상태 변화와 관련된 동사가 이 유형에 많습니다.

| 자동사(자) | 의미 | 타동사(타) | 의미 |
| :--- | :--- | :--- | :--- |
| **壊れる** (こわれる) | 부서지다 | **壊す** (こわす) | 부수다 |
| **倒れる** (たおれる) | 쓰러지다 | **倒す** (たおす) | 쓰러뜨리다 |
| **汚れる** (よごれる) | 더러워지다 | **汚す** (よごす) | 더럽히다 |
| **離れる** (はなれる) | 떨어지다 | **離す** (はなす) | 떼어놓다 |

---

## 5. 예외 및 주의해야 할 쌍
형태가 비슷하거나 불규칙하여 헷갈리기 쉬운 단어들입니다.

* **入る (はいる, 자)** 들어가다 / **入れる (いれる, 타)** 넣다
* **聞こえる (きこえる, 자)** 들리다 / **聞く (きく, 타)** 듣다
* **見える (みえる, 자)** 보이다 / **見る (みる, 타)** 보다
* **焼ける (やける, 자)** 구워지다 / **焼く (やく, 타)** 굽다

---

1. **이동 동사의 예외**
   - '길을 걷다(道を歩く)', '하늘을 날다(空を飛ぶ)'처럼 자동사임에도 **통과하는 장소**를 나타낼 때 「を」를 쓰는 경우가 있으니 주의하세요.

# ✍️ 독학사 일본어 빈출 관용 표현 정리

'명사 + 조사 + 동사'의 조합으로 이루어진 표현들 중, 시험에 자주 나오며 조사가 헷갈리기 쉬운 핵심 표현들입니다.

---

## 1. 신체 및 건강 관련 표현
가장 기본적인 생활 표현으로, 조사 「を」와 「が」의 구분에 주의해야 합니다.

| 관용 표현 | 읽기 | 의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **お風呂に入る** | おふろにはいる | 목욕을 하다 | '들어가다' 동사 사용 |
| **風邪をひく** | かぜをひく | 감기에 걸리다 | '걸리다'가 아닌 'ひく' 사용 |
| **熱が出る** | ねつがでる | 열이 나다 | 자동사 '出る' 사용 |
| **お腹が空く** | おなかがすく | 배가 고프다 | '비다(空く)' 동사 사용 |
| **喉が渇く** | のどがかわく | 목이 마르다 | '마르다(渇く)' 동사 사용 |
| **歯を磨く** | はをみがく | 이를 닦다 | '닦다/연마하다' 사용 |

---

## 2. 일상 가사 및 동작 표현
주로 동사 「かける」가 쓰이는 표현들이 시험에 자주 나옵니다.

| 관용 표현 | 읽기 | 의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **掃除機をかける** | そうじきをかける | 청소기를 돌리다 | 'かける'의 다양한 용법 |
| **電話をかける** | でんわをかける | 전화를 걸다 | |
| **アイロンをかける** | あいろんをかける | 다림질을 하다 | |
| **布団を敷く** | ふとんをしく | 이불을 펴다 | '깔다/펴다(敷く)' 사용 |
| **鍵をかける** | かぎをかける | 문을 잠그다 | |

---

## 3. 심리 및 '気(기분/마음)' 관련 표현
독학사 2단계(중급)에서 가장 비중 있게 다루는 관용구들입니다.

| 관용 표현 | 읽기 | 의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **気になる** | きになる | 궁금하다/걱정되다 | 자연스럽게 마음이 쓰임 |
| **気にする** | きにする | 신경 쓰다 | 의식적으로 걱정함 |
| **気に入る** | きにいる | 마음에 들다 | 좋아하게 됨 |
| **気がつく** | きがつく | 깨닫다/알아차리다 | 눈치채다 |
| **気を付ける** | きをつける | 주의하다/조심하다 | |

---

## 4. 기타 사회생활 및 상태 표현

| 관용 표현 | 읽기 | 의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **役に立つ** | やくにたつ | 도움이 되다 | '서다(立つ)' 동사 사용 |
| **間に合う** | まにあう | 시간에 대다 | 늦지 않게 도착하다 |
| **世話をする** | せわをする | 돌보다 | |
| **連絡を取る** | れんらくをとる | 연락을 취하다 | |
| **都合がいい** | つごうがいい | 사정이 좋다(시간이 된다) | |
| **恥をかく** | はじをかく | 창피를 당하다 | 망신을 당하다 |

---

## 💡 독학사 고득점 포인트!

1.  **조사 주의**: '감기에 걸리다'는 「風邪**に**」가 아니라 **「風邪を」**입니다. 한국어 조사에 낚이지 않도록 통째로 외우세요.
2.  **동사 선택**: '청소기를 돌리다'나 '전화를 걸다' 등 많은 동작에 **「かける」**가 만능처럼 쓰입니다. 이 동사가 쓰이는 관용구들을 따로 모아서 정리해두면 문법 문제에서 매우 유리합니다.
3.  **반대말**: 「役に立つ(도움이 되다)」의 반대말은 「役に立たない」처럼, 관용구의 부정형도 시험에 종종 등장합니다.
